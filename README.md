# Twitter Profile Followers (Archived)

> **⚠️ This project is archived and no longer maintained.** The Twitter (now X) API has undergone significant changes, and this plugin may no longer function as expected.

## What It Did

A WordPress plugin that fetched Twitter follower counts for profiles linked via custom fields. If your post or custom post type contained a custom field with a Twitter profile URL or slug, this plugin would fetch the follower count and store it in a separate custom field.

## Why Archived

Twitter's API (now X API) has changed significantly since this plugin was developed, including the introduction of paid API tiers and deprecation of free endpoints. This plugin is no longer compatible with the current API and there are no plans to update it.

## Historical Requirements

- WordPress
- A Twitter Developer App with API credentials

## Installation (Historical)

Download the zip or clone the repo and install as a standard WordPress plugin.
